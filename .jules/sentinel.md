## 2024-05-24 - Credential Exposure in Process List and Temp Files
**Vulnerability:** SQL Server credentials (SQL_PASSWORD) were being passed directly to `sqlcmd` via the `-P` parameter, exposing them to anyone with access to view the process list (e.g., `ps aux`). Additionally, temporary SQL files (`/tmp/setup_cred.sql`, `/tmp/get_dbs.sql`, `/tmp/backup.sql`) containing sensitive credentials (S3 Access Keys and Secrets) were being written directly to disk.
**Learning:** Hardcoded credentials or secrets passed via command-line arguments can easily be logged or viewed by other users on the system. Temporary files on disk may persist or be accessed by unauthorized users before cleanup.
**Prevention:** Always use environment variables (e.g., `SQLCMDPASSWORD`) for passing sensitive data to CLI tools if supported. Prefer bash process substitution (`<()`) to pass dynamically generated content directly to commands instead of writing sensitive data to intermediate temporary files on disk.
